# Secure Calculator with Hidden File Access

**Tech Stack:** HTML, CSS, JavaScript
**Timeline:** 2023–2024
**Current Status:** 80–90% functional

## Description

A calculator application that functions normally for everyday use while supporting password-based secure access. Behind its simple, familiar interface, the app hides protected functionality accessible only through a specific input sequence.

## Features

- Developed a calculator that functions normally while supporting password-based secure access.
- Implemented hidden features to display confidential messages and enable protected file viewing/downloading.
- Designed with future extensibility in mind, including encrypted storage and backend validation.

## Roadmap

- [ ] Encrypted storage for hidden files and messages
- [ ] Backend authentication for real server-side validation
- [ ] Complete remaining 10–20% of core functionality

## Notes

The current password protection is implemented on the client side (JavaScript), which means the logic can be viewed via page source. Backend/server-side authentication is planned to address this limitation.
